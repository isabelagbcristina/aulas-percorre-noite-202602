# BOX MODEL
O CSS enxerga os elementos do HTML como caixas que possuem algumas propriedades.

##  MARGIN 
Margem é o espaço que distância um elemento do outro, ou seeja, é essa medida que faz um paagráfo ir para longe de uma imagem.

## BORDER
Para contornar um elemento podemos configurar uma borda, a borda nada mais é do que uma linha em volta do elemento que fica entre a MARGIN e o PADDING.

## PADDING 
Se a margm é o espaço externo de um elemento, o PADDING é o espaço interno, ele que separa o conteúdo da BORDA e da MARGIN.
